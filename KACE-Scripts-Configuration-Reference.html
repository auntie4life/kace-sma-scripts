KACE migration scripts: configuration reference

For team and Quest KACE review. This reference contains anonymized scripts, not private enrollment details.

Red text identifies information you must supply or an action required before running. Bold dark text identifies defaults you must review; those values may remain unchanged.

Migration script | Sanitizer script

1. Migration script

Configure the actual .ps1 file in your editor. The public copy includes a stop guard; remove it only after replacing all required values and reviewing the remaining settings. Added guidance comments below are reference annotations.

SettingWhat to supply
PilotComputerNameThe exact name of the one authorized pilot computer.
ExpectedSha256The SHA-256 hash of your actual MSI, not the ZIP.
MsiNameThe complete customized MSI filename from your destination SMA, including its enrollment token. The script extracts the token from this filename.
TargetHostYour destination SMA hostname, matching the intended installer.
LegacyProductCodeThe MSI product code verified on your legacy endpoint.
Other configuration settingsVerify ZIP name, old and new versions, staging folder, and scheduled task name. Match versions to the actual packages. The configured MSI must be at the ZIP root.

A successful launching KACE job confirms staging only. Confirm worker logs, installed version, server assignment, and fresh destination inventory. Automatic reboots are suppressed; a reboot requirement can still stop migration. No automatic rollback is provided.

# Migrate-KACE.ps1
#
# ONE-COMPUTER PILOT:
# Legacy agent 11.0.119 -> agent 15.1.55 on sma.example.invalid
#
# Legacy KACE dependencies:
#   Migrate-KACE.ps1
#   Agent-Bundle.zip
#
# ZIP contents: the specified MSI directly inside the ZIP.
#
# Run as Local System using 64-bit Windows PowerShell.
# Do not pass -Worker from KACE.
#
# No automatic reboot, retry, or rollback is performed.
# The independent scheduled task remains available for inspection.
# Protect the staged files and logs because they contain the test token.

param(
    [switch]$Worker
)

# SANITIZED REVIEW COPY. Reconfigure and remove this guard only after review.
# REQUIRED: remove this review-only guard only after completing configuration and testing
throw 'Review-only sanitized template. Configure and validate before deployment.'
$ErrorActionPreference = 'Stop'

# ---------- Pilot configuration ----------
# REQUIRED: replace with your environment value
$PilotComputerName = 'REPLACE_WITH_PILOT_COMPUTER'
# REQUIRED: replace with your environment value
$ExpectedSha256 = 'REPLACE_WITH_MSI_SHA256'

# REVIEW: keep or update for your deployment
$ZipName = 'Agent-Bundle.zip'
# REQUIRED: replace with your environment value
$MsiName = 'ampagent-15.1.55-x64_sma.example.invalid+REPLACE_WITH_AGENT_TOKEN.msi'

# REQUIRED: replace with your environment value
$TargetHost = 'sma.example.invalid'
# REVIEW: keep or update for your deployment
$ExpectedNewVersion = '15.1.55'
# REVIEW: keep or update for your deployment
$LegacyVersion = '11.0.119'
# REQUIRED: replace with your environment value
$LegacyProductCode = '{REPLACE_WITH_LEGACY_PRODUCT_CODE}'

$TargetToken = [IO.Path]::GetFileNameWithoutExtension($MsiName).Split('+', 2)[1]

# REVIEW: keep or update for your deployment
$Stage = 'C:\ProgramData\MigrationExample'
# REVIEW: keep or update for your deployment
$TaskName = 'Example-KACE-Agent-Migration'
$StagedScript = Join-Path $Stage 'Migrate-KACE.ps1'
$MsiPath = Join-Path $Stage $MsiName
$LogPath = Join-Path $Stage 'Migration.log'
$PowerShellExe = "$env:SystemRoot\System32\WindowsPowerShell\v1.0\powershell.exe"

# ---------- Functions ----------
function Write-MigrationLog {
    param([string]$Message)

    Add-Content -LiteralPath $LogPath -Value `
        "$(Get-Date -Format o) $Message"
}

function Get-KaceAgent {
    $Paths = @(
        'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*'
        'HKLM:\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*'
    )

    Get-ItemProperty -Path $Paths -ErrorAction SilentlyContinue |
        Where-Object { $_.DisplayName -eq 'KACE Agent' }
}

function Assert-LegacyAgent {
    $Agent = @(Get-KaceAgent)

    if ($Agent.Count -ne 1) {
        throw 'Expected exactly one installed KACE Agent. No uninstall attempted.'
    }

    if ($Agent[0].DisplayVersion -ne $LegacyVersion -or
        $Agent[0].PSChildName -ne $LegacyProductCode) {
        throw 'Installed agent does not match the expected legacy version and product code.'
    }
}

function Assert-StagedInstaller {
    if (-not (Test-Path -LiteralPath $MsiPath -PathType Leaf)) {
        throw "Expected MSI is missing: $MsiPath"
    }

    $ActualHash = (
        Get-FileHash -LiteralPath $MsiPath -Algorithm SHA256
    ).Hash

    if ($ActualHash -ne $ExpectedSha256) {
        throw 'MSI hash mismatch. Stop before uninstalling anything.'
    }
}

function Assert-TargetReachable {
    # TCP reachability only. Does not validate the token or enrollment.
    $Reachable = Test-NetConnection -ComputerName $TargetHost `
        -Port 443 -InformationLevel Quiet `
        -WarningAction SilentlyContinue

    if (-not $Reachable) {
        throw 'Test SMA HTTPS connection failed. No uninstall attempted.'
    }
}

function Invoke-Msi {
    param(
        [string]$Arguments,
        [string]$Operation
    )

    $Process = Start-Process `
        -FilePath "$env:SystemRoot\System32\msiexec.exe" `
        -ArgumentList $Arguments -Wait -PassThru

    Write-MigrationLog "$Operation exit code: $($Process.ExitCode)"

    if ($Process.ExitCode -eq 3010) {
        throw "$Operation requires a reboot. No reboot initiated. Stop and review."
    }

    if ($Process.ExitCode -ne 0) {
        throw "$Operation failed with code $($Process.ExitCode). Review MSI logs."
    }
}

# ---------- Safety checks ----------
if ($env:COMPUTERNAME -ne $PilotComputerName) {
    throw "Wrong computer. This script is restricted to $PilotComputerName."
}

if (-not [Environment]::Is64BitProcess -or
    $env:PROCESSOR_ARCHITECTURE -ne 'AMD64') {
    throw 'Use 64-bit Windows PowerShell on an AMD64 Windows endpoint.'
}

$CurrentSid = [Security.Principal.WindowsIdentity]::GetCurrent().User.Value

if ($CurrentSid -ne 'S-1-5-18') {
    throw 'Run this script as Local System.'
}

if ([string]::IsNullOrWhiteSpace($TargetToken)) {
    throw 'Test token could not be read from the MSI filename.'
}

# ---------- Stage files and launch independent worker ----------
if (-not $Worker) {
    Assert-LegacyAgent

    if (Test-Path -LiteralPath $Stage) {
        throw "Staging folder already exists. Review the previous attempt: $Stage"
    }

    if (Get-ScheduledTask -TaskName $TaskName -ErrorAction SilentlyContinue) {
        throw 'Migration task already exists. Review before retrying.'
    }

    $SourceZip = Join-Path $PSScriptRoot $ZipName

    if (-not (Test-Path -LiteralPath $SourceZip -PathType Leaf)) {
        throw "ZIP dependency is missing: $SourceZip"
    }

    New-Item -Path $Stage -ItemType Directory -Force | Out-Null

    # Restrict the staging folder to SYSTEM and Administrators.
    & "$env:SystemRoot\System32\icacls.exe" $Stage `
        /inheritance:r `
        /grant:r '*S-1-5-18:(OI)(CI)F' '*S-1-5-32-544:(OI)(CI)F' |
        Out-Null

    if ($LASTEXITCODE -ne 0) {
        throw 'Unable to secure the staging folder.'
    }

    try {
        Expand-Archive -LiteralPath $SourceZip -DestinationPath $Stage

        Copy-Item -LiteralPath $PSCommandPath `
            -Destination $StagedScript -Force

        Assert-StagedInstaller
        Assert-TargetReachable

        $Action = New-ScheduledTaskAction `
            -Execute $PowerShellExe `
            -Argument "-NoProfile -NonInteractive -ExecutionPolicy Bypass -File `"$StagedScript`" -Worker" `
            -WorkingDirectory $Stage

        $Principal = New-ScheduledTaskPrincipal `
            -UserId 'SYSTEM' `
            -LogonType ServiceAccount `
            -RunLevel Highest

        $Settings = New-ScheduledTaskSettingsSet `
            -ExecutionTimeLimit (New-TimeSpan -Hours 2) `
            -AllowStartIfOnBatteries `
            -DontStopIfGoingOnBatteries

        Register-ScheduledTask -TaskName $TaskName `
            -Action $Action `
            -Principal $Principal `
            -Settings $Settings |
            Out-Null

        Write-MigrationLog 'Staging completed. Launching independent worker.'

        Start-ScheduledTask -TaskName $TaskName

        Write-Output 'Independent migration task launched.'
        Write-Output 'This confirms staging only, not completed migration.'
        Write-Output "Review $LogPath and inventory in the test SMA."
        exit 0
    }
    catch {
        Write-MigrationLog "STAGING STOPPED: $($_.Exception.Message)"
        throw
    }
}

# ---------- Independent migration worker ----------
$Mutex = New-Object System.Threading.Mutex(
    $false,
    'Global\Example-KACE-Agent-Migration'
)

$LockHeld = $false
$WorkerExitCode = 1

try {
    $LockHeld = $Mutex.WaitOne(0)

    if (-not $LockHeld) {
        throw 'Another migration worker is already running.'
    }

    Write-MigrationLog "Worker started on $env:COMPUTERNAME."

    Assert-StagedInstaller
    Assert-LegacyAgent
    Assert-TargetReachable

    # Remove legacy agent without initiating a Windows Installer reboot.
    $UninstallLog = Join-Path $Stage 'Legacy-Uninstall.log'

    Invoke-Msi -Operation 'Legacy uninstall' -Arguments `
        "/x $LegacyProductCode /qn /norestart /L*v `"$UninstallLog`""

    if (@(Get-KaceAgent).Count -ne 0) {
        throw 'KACE Agent registration remains after uninstall. Stop and review.'
    }

    # Install test agent without initiating a Windows Installer reboot.
    $InstallLog = Join-Path $Stage 'Test-Agent-Install.log'

    Invoke-Msi -Operation 'Test agent install' -Arguments `
        "/i `"$MsiPath`" /qn /norestart HOST=`"$TargetHost`" TOKEN=`"$TargetToken`" /L*v `"$InstallLog`""

    $Agent = @(Get-KaceAgent)

    if ($Agent.Count -ne 1 -or
        $Agent[0].DisplayVersion -ne $ExpectedNewVersion) {
        throw 'Expected test agent version was not found after installation.'
    }

    Write-MigrationLog 'Agent 15.1.55 installation completed.'
    Write-MigrationLog 'Verify server assignment, running services, and successful inventory in the test SMA.'

    $WorkerExitCode = 0
}
catch {
    Write-MigrationLog "WORKER STOPPED: $($_.Exception.Message)"
}
finally {
    if ($LockHeld) {
        $Mutex.ReleaseMutex()
    }

    $Mutex.Dispose()
}

exit $WorkerExitCode

2. Sanitizer script

This script normally needs no edits internally. Supply your own paths when invoking it. It reads the identifying settings from your source script and replaces them throughout a separate copy. It never runs the migration or changes the original.

Required command inputs

.\Sanitize-KACEMigration.ps1 -InputPath 'C:\YOUR-PRIVATE-FOLDER\Migrate-KACE.ps1' -OutputPath 'C:\YOUR-SHARING-FOLDER\Migrate-KACE.public.ps1'

Replace both red paths. The input must exist, and the output must be a different, new file. The destination folder must already exist.

The replacement settings inside the sanitizer are deliberately anonymous. Keep them anonymous; do not enter your private hostname or enrollment token there. If your source script structure changes, review the sanitizer mapping before using it again.

<#
Creates a separate review-only copy of the supplied migration pilot.
Never executes the migration or changes the original.
Example: .\Sanitize-KACEMigration.ps1 -InputPath .\Migrate-KACE.ps1 -OutputPath .\Migrate-KACE.public.ps1
#>
[CmdletBinding()]
param(
    [Parameter(Mandatory = $true)][string]$InputPath,
    [Parameter(Mandatory = $true)][string]$OutputPath
)
$ErrorActionPreference = 'Stop'
$Source = (Resolve-Path -LiteralPath $InputPath).ProviderPath
$Destination = $ExecutionContext.SessionState.Path.GetUnresolvedProviderPathFromPSPath($OutputPath)
if ($Source -eq $Destination) { throw 'Choose a different output file.' }
if (Test-Path -LiteralPath $Destination) { throw 'Output already exists. Choose a new filename.' }
$Text = [IO.File]::ReadAllText($Source)
# Values come from the source. No real identifiers are embedded in this sanitizer.
$Settings = [ordered]@{
    PilotComputerName = 'REPLACE_WITH_PILOT_COMPUTER'
    ExpectedSha256 = 'REPLACE_WITH_MSI_SHA256'
    ZipName = 'Agent-Bundle.zip'
    MsiName = 'ampagent-15.1.55-x64_sma.example.invalid+REPLACE_WITH_AGENT_TOKEN.msi'
    TargetHost = 'sma.example.invalid'
    LegacyProductCode = '{REPLACE_WITH_LEGACY_PRODUCT_CODE}'
    Stage = 'C:\ProgramData\MigrationExample'
    TaskName = 'Example-KACE-Agent-Migration'
}
$Replacements = @{}
foreach ($Name in $Settings.Keys) {
    $Pattern = '(?m)^\s*\$' + [regex]::Escape($Name) + '\s*=\s*''(?<value>[^''\r\n]+)''\s*\r?$'
    $MatchesFound = [regex]::Matches($Text, $Pattern)
    if ($MatchesFound.Count -ne 1) {
        throw "Expected exactly one literal assignment for $Name. No output written."
    }
    $Old = $MatchesFound[0].Groups['value'].Value
    if ($Old.Length -lt 4) { throw "Unexpected short value for $Name. No output written." }
    $Replacements[$Old] = $Settings[$Name]
    if ($Name -eq 'MsiName') {
        $Parts = [IO.Path]::GetFileNameWithoutExtension($Old).Split('+', 2)
        if ($Parts.Count -ne 2 -or [string]::IsNullOrWhiteSpace($Parts[1])) {
            throw 'Expected a customized MSI filename containing a token. No output written.'
        }
        $Replacements[$Parts[1]] = 'REPLACE_WITH_AGENT_TOKEN'
    }
}
# Replace longer values first, including repetitions in comments and mutex names.
foreach ($Old in @($Replacements.Keys | Sort-Object -Property Length -Descending)) {
    $Text = $Text.Replace($Old, $Replacements[$Old])
}
foreach ($Old in $Replacements.Keys) {
    if ($Text.Contains($Old)) { throw 'A configured identifier remains. No output written.' }
}
# Insert after param(), preserving PowerShell's script parameter syntax.
$Guard = @'
# SANITIZED REVIEW COPY. Reconfigure and remove this guard only after review.
throw 'Review-only sanitized template. Configure and validate before deployment.'
'@
$Anchor = '$ErrorActionPreference = ''Stop'''
if (-not $Text.Contains($Anchor)) { throw 'Expected safety insertion point missing. No output written.' }
$Text = $Text.Replace($Anchor, $Guard + "`r`n" + $Anchor)
$Tokens = $null
$ParseErrors = $null
$null = [System.Management.Automation.Language.Parser]::ParseInput($Text, [ref]$Tokens, [ref]$ParseErrors)
if ($ParseErrors.Count -gt 0) { throw 'Sanitized output has syntax errors. No output written.' }
$Stream = [IO.File]::Open($Destination, [IO.FileMode]::CreateNew, [IO.FileAccess]::Write)
try {
    $Bytes = (New-Object System.Text.UTF8Encoding($true)).GetBytes($Text)
    $Stream.Write($Bytes, 0, $Bytes.Length)
}
finally { $Stream.Dispose() }
Write-Output "Created review-only copy: $Destination"
Write-Output 'Original unchanged. Review the entire copy before sharing.'

Review the whole sanitized file before sharing. This sanitizer targets the current pilot structure; it does not sanitize installers, ZIP files, logs, newly introduced identifiers, or Git history. The sanitizer has not been execution-tested in Windows PowerShell in this workspace.
